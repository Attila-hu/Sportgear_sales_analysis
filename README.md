SportGear Sales and Payment Performance Analysis
 
Project overview
This project analyzes sales, customer, product and payment data
for a fictional international sporting goods company.
 
Business questions
- Which countries generate the highest revenue?
- Which products and product groups perform best?
- How did revenue change between 2023 and 2024?
- Which customer segments generate the most revenue?
- Where is the greatest overdue-payment risk?
 
Tools
- SQLite
- SQL
- Microsoft Excel
- Power Query
- Power BI
- GitHub
 
Analysis process
1. Data quality validation
2. Relational database creation
3. SQL analysis
4. KPI calculation
5. Power BI visualization
6. Business recommendations
